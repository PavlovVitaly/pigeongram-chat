Как импортировать дашборд

    Откройте Grafana: http://localhost:3000

    Войдите: admin/admin

    Импортируйте дашборд:

        Нажмите + → Import

        Вставьте JSON код выше

        Выберите datasource Prometheus

        Нажмите Import

📊 Что показывает дашборд
